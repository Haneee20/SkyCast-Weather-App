# SkyCast Weather App

A responsive weather website built with Flask, Python, HTML, CSS and JavaScript. It uses the Open-Meteo API to search for locations and display current weather information.

## Features
- Search for locations with autocomplete suggestions
- View current temperature
- View relative humidity
- View wind speed
- Responsive user interface

## Technologies Used
- Python
- Flask
- HTML and CSS
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## Run Locally

1. Install Python.
2. Clone this repository.
3. Install the dependencies:

   `py -m pip install flask requests`

4. Run the application:

   `py app.py`

5. Open `http://127.0.0.1:5000` in your browser.

## Weather Data
Weather and location data are provided by Open-Meteo: https://open-meteo.com/
